# 도깨비 지갑 (DOKKAEBI WALLET)

> 우리 가족의 돈과 일상을 담는 지갑

가족 구성원들이 함께 가계부, 디지털 지갑, 캘린더, 공지사항, 할 일을 관리하는 가족 통합 관리 iOS 네이티브 앱.

- iOS 17+ · Swift · SwiftUI · MVVM
- Supabase (Auth, PostgreSQL, Storage, Realtime, Edge Functions) · Swift Charts
- 한국어 · KRW · Asia/Seoul
