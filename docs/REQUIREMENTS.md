# 도깨비 지갑 — 요구사항 명세서

요구사항 ID 규칙: `FR-<영역>-<번호>` (기능), `NFR-<번호>` (비기능).
우선순위: **P0** = MVP 필수, **P1** = 정식 출시 필수, **P2** = 출시 후 확장.
참조하는 핵심 결정(D1~D12)은 PROJECT_PLAN.md §3에 있다.
