## 2. 핵심 흐름

### F1. 첫 실행과 가입
```
S-AUTH-01 시작
 ├─ [Apple로 계속하기] → Apple 시트 → (처음 가입) S-AUTH-03 / (기존 사용자) 홈
 ├─ [카카오로 계속하기] → 웹 인증 세션 → 같은 분기
 └─ [이메일로 계속하기] → S-AUTH-02 이메일 입력 → 6자리 코드 입력 (재전송 60초 제한)
S-AUTH-03 프로필 (이름 필수, 사진 선택)
 → 대기 중인 초대 링크가 있으면 S-ONB-03으로 바로 이동
 → 없으면 S-ONB-01 [새 가족 만들기] / [초대 코드 입력]
S-ONB-02 그룹 이름, 월 시작일 → 생성 (기본 카테고리 자동 생성)
 → S-ONB-04 알림 권한 안내 → [허용] 시스템 팝업 / [나중에]
 → S-FAM-03 "가족을 초대해 보세요" (건너뛸 수 있음) → 홈
```
예외: OTP 5회 실패 → 10분 잠금 안내. 네트워크 오류 → 재시도 버튼.

### F2. 가족 초대와 참여
```
[초대하는 사람] 가족 관리 → [초대하기] → 역할 선택 (관리자는 소유자만 지정 가능)
  → 링크와 코드 생성 → 공유 시트 (카카오톡, 메시지 등)
[초대받는 사람] 링크를 누름
  ├─ 앱 설치됨 → Universal Link → (로그인 상태) S-ONB-03
  │                              → (로그아웃 상태) 로그인 후 S-ONB-03 (토큰을 Keychain에 잠시 보관)
  └─ 앱 미설치 → 웹 랜딩 페이지 → App Store → 설치 후 처음 실행할 때 코드 입력 안내
S-ONB-03: "OO님이 '우리집' 가족에 초대했어요 · 구성원 3명" [참여하기] / [거절]
  → 참여 → 그룹을 전환하고 홈으로 → 기존 구성원들에게 "OO님이 참여했어요" 알림
```
예외: 만료 / 사용 횟수 초과 / 인원 초과 / 이미 구성원 → 각각에 맞는 안내 문구.

### F3. 지출 등록 (가장 자주 쓰는 흐름)
```
진입점: 홈 [+] → 지출 / 가계부 [+] / 위젯(P2)
S-LED-03 (sheet, 금액 입력란에 포커스)
 1. 금액 (숫자 키패드, +1만, +5천 빠른 버튼)
 2. 유형 세그먼트 [지출|수입|이체] (기본값: 지출)
 3. 카테고리 그리드 (최근 사용 순, 사용 중지된 항목 제외)
 4. 날짜·시간 (기본값: 지금)
 5. 결제수단
 6. 사용처 (자동완성) / 메모
 7. 구분 [공동|개인]
 8. 실사용자 (구성원 아바타 선택, 기본값: 나)
 9. 공개 범위 [가족 전체|나만|선택]  ← 공동을 고르면 '가족 전체'로 고정하고 안내 문구 표시
10. 영수증 [촬영|앨범|스캔]
11. 반복 설정 (선택)
[저장] → sheet 닫힘 → 목록에 즉시 반영 (오프라인이면 시계 아이콘)
     → 서버 저장 → 다른 구성원 화면에 실시간 반영, 권한이 있는 구성원에게 푸시
     → 예산 임계치를 넘으면 예산 알림
```
- 필수 입력은 금액과 카테고리뿐이다. 나머지는 기본값으로 처리해 3번 탭 안에 저장할 수 있다.
- 공개 범위를 "선택"으로 고르면 구성원을 여러 명 고르는 시트가 열린다. 0명이면 저장 버튼이 비활성화된다.
- 이체를 고르면 카테고리 영역 대신 [보내는 계좌 → 받는 계좌]가 나온다.

### F4. 거래 수정과 삭제
```
S-LED-04 상세 → [수정] → S-LED-03 (수정 모드)
  반복 거래에서 온 항목이면 → "이 거래만 / 이후 모든 반복" 선택
  저장할 때 충돌하면 → 충돌 시트 (APP_STRUCTURE.md §8.2)
목록 스와이프 / 상세 [삭제] → 확인 → 삭제 → "삭제했어요 [실행 취소]" 5초
```
권한이 없으면(다른 사람의 개인 거래) 수정과 삭제 버튼을 보여주지 않는다.

### F5. 거래 검색과 기간 조회
```
S-LED-01 상단 월 선택 (‹ 2026년 11월 ›) / 기간 칩 [이번 달 ▾]
검색창에 키워드 입력 (300ms 디바운스) → 서버 검색 (오프라인이면 로컬)
[필터] → S-LED-02: 유형, 카테고리, 결제수단, 구분, 실사용자, 금액 범위 → [적용]
결과 상단에 합계 요약 (수입, 지출, 건수)
```

### F6. 예산 설정과 알림
```
가계부 → [예산] 세그먼트 → (예산 없음) 빈 화면 [예산 설정하기]
S-LED-08: 가족 / 개인 탭 → 총예산 → 카테고리별 예산 (선택) → [지난달 예산 불러오기]
저장 → 진행률 표시
지출 누적이 80%를 넘으면 → 푸시 "이번 달 가족 예산의 80%를 사용했어요"
100%를 넘으면 → 푸시, 홈 예산 카드가 위험 색으로 바뀜
```
구성원(member) 역할은 가족 예산을 볼 수만 있다 (편집 버튼 숨김).

### F7. 통계 보기
```
가계부 → [통계] 세그먼트
기간 선택 (월 / 직접 지정) → 요약 (총지출, 전월 대비 ▲12%)
 → 카테고리 도넛 → 카테고리를 누르면 필터된 내역 (S-LED-01)
 → 구성원별 막대 / 공동 vs 개인 / 월별 추이
하단 고정 안내: "ⓘ 내가 볼 수 있는 내역을 기준으로 집계했어요"
```

### F8. 카테고리 관리
```
가계부 ⋯ → 카테고리 관리 (S-LED-10)  [지출|수입] 세그먼트
 ├─ [+] → S-LED-11: 이름, 아이콘, 색상 → 저장 → 다른 구성원 화면에 실시간 추가
 ├─ 항목 길게 누르기 / 편집 모드 → 드래그 정렬
 ├─ 항목 → 편집 / [사용 중지] 토글
 └─ [삭제] → (사용 중인 거래 N건) "다른 카테고리로 옮긴 뒤 삭제할게요" → 대체 카테고리 선택 → 삭제
권한 없음 (구성원이고 그룹 설정이 관리자 전용) → 읽기 전용, 안내 배너
```

### F9. 지갑 카드 등록과 사용
```
지갑 탭 [+] → S-WAL-02
 ├─ [카메라로 스캔] → S-WAL-03 실시간 인식 (유형 자동 감지, 진동 피드백) → S-WAL-04 (값과 유형이 미리 채워짐)
 ├─ [사진에서 가져오기] → PhotosPicker → Vision 인식 → 여러 개 인식되면 선택 → S-WAL-04
 └─ [직접 입력] → S-WAL-04
S-WAL-04: 브랜드명*, 카드명, 번호, 바코드 유형, 메모, 색상, 로고 / [개인 지갑 | 가족 공유] 선택 → 저장
  (번호가 Luhn 검사를 통과하면 "결제카드 번호는 저장하지 마세요" 경고)
사용: 목록에서 카드를 누름 → S-WAL-06 바로 전체 화면 (밝기 최대)
     → 좌우 스와이프로 다른 카드 / 아래로 쓸어 닫으면 밝기 복원
오프라인: 같은 흐름이 모두 동작한다 (캐시된 바코드 이미지 사용)
지갑 잠금을 켰으면 탭에 들어갈 때 Face ID
```

### F10. 일정 등록
```
캘린더 [+] 또는 날짜 칸 길게 누르기 → S-CAL-03
 제목*, 종일 토글, 시작·종료, 장소, 설명
 구분 [가족 | 개인 | 선택한 구성원]
 참여자 (구성원 선택) · 반복 · 알림 (최대 2개) · 색상
저장 → 로컬 알림 예약 → 참여자에게 푸시 "새 일정: 할머니 생신 (11/30)"
반복 일정 수정·삭제 → "이 일정만 / 이후 일정 / 모든 일정"
참여자 → 일정 상세에서 [참석|미정|불참] 응답
```

### F11. 공지사항
```
전체 → 공지사항 → [작성] → S-NOT-03: 제목, 본문, 이미지 (최대 10장), [상단 고정] (관리자만 보임)
게시 → 구성원에게 푸시 → 목록 맨 위 (고정 공지 다음)
구성원이 푸시를 누름 → S-NOT-02 → 자동으로 읽음 기록
작성자·관리자 → 상세의 "3/4명 읽음" → S-NOT-04 (읽은 사람과 시각 / 안 읽은 사람)
```

### F12. 할 일
```
전체 → 할 일 → [내 할 일 | 가족 | 완료] 탭
[+] → S-TASK-02: 제목*, 설명, 담당자 (여러 명), 마감일·시간, 중요도, 공개 범위, 반복
저장 → 담당자에게 푸시 "OO님이 '분리수거'를 맡겼어요"
목록에서 체크 → 완료 (줄 긋기 애니메이션, 햅틱) → 완료 탭으로 이동, 실행 취소 가능
상태를 길게 눌러 [예정 → 진행 중 → 완료]
마감 당일 9시 로컬 알림, 마감 초과 시 서버 푸시
```

### F13. 알림 센터
```
종 아이콘 (배지 N) → S-NTF-01
 섹션: 오늘 / 이번 주 / 이전   · 그룹 필터 [현재 그룹 | 전체]
 항목을 누름 → 읽음 처리 + 딥링크 이동 (다른 그룹 항목이면 그룹 전환 확인)
 스와이프 → 삭제 / 상단 [모두 읽음]
 원본 데이터가 삭제됐거나 권한이 없으면 "더 이상 볼 수 없는 항목이에요"
```

### F14. CSV 가져오기
```
가계부 ⋯ → CSV 가져오기 → 1. 파일 선택 (파일 앱 / 다른 앱 공유 시트로 열기)
 → 2. 결제수단 연결 (어느 계좌·카드의 내역인지)
 → 3. 열 매핑 (저장된 프리셋 자동 적용, 첫 5행 미리보기)
 → 4. 기본값: 구분 [공동|개인], 공개 범위
 → 5. 미리보기: 신규 N / 중복 의심 M / 오류 K. 행별 카테고리 자동 분류 결과, 체크 해제 가능
 → 6. [가져오기] → 진행 표시 → 완료 요약 → [가져오기 기록] (되돌리기 가능)
같은 파일을 다시 가져오면 경고 ("이미 가져온 파일이에요")
```

### F15. 그룹 탈퇴와 내보내기
```
가족 관리 → 구성원 상세 (본인) → [그룹 나가기]
 소유자면 → "먼저 소유권을 넘겨 주세요" → 구성원 선택 → 이전
 확인 시트: "나만 보기로 저장한 거래 N건과 개인 일정이 삭제돼요. [내보내기 후 나가기] / [나가기]"
 → 다른 그룹이 있으면 그 그룹으로 전환, 없으면 S-ONB-01
관리자가 내보내기: 구성원 상세 → [내보내기] → 확인 → 대상자에게 알림
```

### F16. 그룹 전환
```
홈·가계부 상단 그룹 이름 ▾ → S-GRP-01 (참여 중인 그룹, 역할 표시, 그룹별 읽지 않은 알림 수)
 → 다른 그룹 선택 → 캐시 범위 전환, Realtime 재구독 → 화면 새로고침 (스켈레톤 300ms 이내)
 → [새 그룹 만들기] / [초대 코드로 참여]
```

### F17. 계정 삭제
```
설정 → 계정 → [계정 삭제]
 소유한 그룹이 있으면 → 그룹별로 [소유권 이전] 또는 [그룹 삭제]를 마쳐야 다음 단계로
 안내: 삭제되는 데이터 (개인 데이터 전부) / 남는 데이터 (공동 기록은 '탈퇴한 구성원'으로 표시)
 재인증 (Apple / OTP) → 최종 확인 → Edge Function `delete-account` → 로그아웃, 로컬 데이터 삭제
```
